# WorldSimulation 🗿

A Python-based society simulation where artificial citizens live, interact, evolve, and eventually die.

The goal is to build a living virtual world governed by rules defined by the simulation rather than scripted stories.

## Current State

**Version:** V0

Currently, the simulation can:
- Generate random citizen names
- Generate starting money
- Create citizens

## Planned Features

- Time progression
- Age and death
- Happiness and needs
- Jobs and salaries
- Economy
- Relationships and families
- Events
- Laws and world rules
- Population statistics
- More complex interactions between citizens

## Project Goal

The long-term goal is to create a simulation where I can define or change rules and observe how the society evolves as a result.

This project is also a way for me to improve my Python and software development skills through a long-term project.

## Technologies

- Python
- Git
- GitHub

## AI-Assisted Learning

I am building this project as a way to learn and improve my Python and software development skills.

I use AI as a learning assistant and technical advisor: to explain concepts, discuss design decisions, help debug problems, and challenge my reasoning.

The project is developed progressively, with the goal of understanding and writing the code myself rather than blindly generating it.
